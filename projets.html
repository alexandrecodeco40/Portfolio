> ce que j'ai développé

Projets

Trois applications web développées de A à Z durant mon stage de 1re année de BTS, au service informatique de la Mairie de Saint-Claude.

GestConges

  • PHP
  • MySQL
  • FullCalendar

Application de gestion des congés pour les agents de la mairie, avec plusieurs niveaux de validation. Le projet le plus complexe des trois, et le dernier réalisé.

Contexte & objectifs

Le service avait besoin d'un outil pour centraliser les demandes de congés et leur validation, en remplacement d'un suivi papier ou tableur. L'objectif était un système multi-rôles, du dépôt de la demande par l'agent jusqu'à la validation finale.

Technologies utilisées

PHP natif et MySQL, avec FullCalendar pour l'affichage du calendrier des congés. Accès à la base via une fonction getDB() centralisée et une configuration par constante APP_URL. Application hébergée sur le réseau interne de la mairie.

Difficultés rencontrées

Gérer 5 rôles différents (agent, responsable, RH, DGS, admin) avec un affichage et des droits adaptés à chacun. Le calcul des congés en demi-journées a demandé plusieurs itérations : une première version basée sur les heures s'est révélée trop complexe à maintenir et a été remplacée.

Solutions apportées

Navigation et filtrage des données conditionnés par le rôle de l'utilisateur connecté. Refonte du système de durée de congés sur la base de demi-journées, plus simple à comprendre pour les utilisateurs et plus fiable à calculer.

Compétences développées

  • Conception de BDD multi-tables
  • Gestion de droits par rôle
  • Intégration d'une librairie JS (FullCalendar)
  • Débogage (sessions, affichage conditionnel)

GestInter

  • PHP
  • MySQL
  • Bootstrap

Application de suivi des interventions techniques du service informatique.

Contexte & objectifs

Le service avait besoin de tracer les interventions réalisées par les techniciens (type d'intervention, matériel concerné, statut) pour garder un historique exploitable.

Technologies utilisées

PHP natif (sans framework), MySQL/MariaDB, Bootstrap pour l'interface. Développement avec Laragon, HeidiSQL et VS Code. Déploiement sur une VM accessible depuis le réseau local.

Difficultés rencontrées

Sécuriser l'authentification des utilisateurs et faire fonctionner correctement l'application une fois déployée sur le réseau local, et non plus en local sur mon poste.

Solutions apportées

Mise en place d'une authentification avec mots de passe hashés en bcrypt, et configuration d'une constante d'URL adaptée à l'accès réseau. Déploiement sur la VM via clé USB, avec une documentation Word pour expliquer l'installation.

Compétences développées

  • Authentification sécurisée (bcrypt)
  • Conception de BDD (5 tables)
  • Déploiement sur un réseau local
  • Rédaction de documentation technique

GestMateriel

  • PHP
  • MySQL
  • Python

Application de gestion du parc informatique et des attributions de matériel aux agents.

Contexte & objectifs

Le parc matériel de la mairie était suivi dans un fichier Excel. L'objectif était de créer un outil web pour consulter et gérer l'inventaire et les attributions de matériel.

Technologies utilisées

PHP natif, MySQL/MariaDB pour une base à 3 tables. Un script Python avec la librairie openpyxl a été écrit pour importer les données existantes depuis le fichier Excel.

Difficultés rencontrées

Reprendre proprement des données réelles déjà existantes (environ 193 matériels et 133 attributions) sans erreur ni doublon lors de l'import dans la base.

Solutions apportées

Script Python dédié à l'import, qui lit le fichier Excel et insère les données dans la base MySQL. Application documentée avec un fichier Word, comme pour GestInter.

Compétences développées

  • Scripting Python (openpyxl)
  • Import / migration de données réelles
  • Conception de BDD (3 tables)
