01

GestConges

Application de gestion des congés des agents de la mairie

  • TypeApplication web interne
  • ContexteStage 1re année
  • ComplexitéProjet le plus avancé des trois
  • HébergementRéseau interne de la mairie

Contexte & objectifs

Le service avait besoin d'un outil pour centraliser les demandes de congés et leur validation, en remplacement d'un suivi papier ou tableur. L'objectif était un système multi-rôles, du dépôt de la demande par l'agent jusqu'à la validation finale.

Fonctionnalités principales

  • Espace personnel avec les compteurs de congés de chaque agent
  • Dépôt de demandes de congés, en demi-journées
  • Calendrier des absences (FullCalendar)
  • Circuit de validation et suivi des absences pour les responsables
  • Navigation et droits adaptés à 5 rôles : agent, responsable, RH, DGS, admin

Technologies utilisées

PHP natif et MySQL, avec FullCalendar pour l'affichage du calendrier. Accès à la base via une fonction getDB() centralisée et une configuration par constante APP_URL. Interface en CSS personnalisé.

Difficultés & solutions

Gérer 5 rôles avec un affichage et des droits propres à chacun : la navigation et le filtrage des données dépendent du rôle de l'utilisateur connecté. Le calcul des congés a aussi demandé plusieurs itérations : une première version basée sur les heures, trop complexe à maintenir, a été remplacée par un système en demi-journées, plus simple et plus fiable.

Compétences développées

  • Conception de BDD multi-tables
  • Gestion de droits par rôle
  • Intégration d'une librairie JS
  • Débogage (sessions, affichage conditionnel)
02

GestInter

Application de suivi des interventions du service informatique

  • TypeApplication web interne
  • ContexteStage 1re année
  • Base de données5 tables
  • HébergementVM sur le réseau local

Contexte & objectifs

Le service avait besoin de tracer les interventions réalisées par les techniciens (type d'intervention, matériel concerné, statut) pour garder un historique exploitable.

Fonctionnalités principales

  • Création d'une nouvelle intervention
  • Suivi par statut : reçue, en cours, résolue, clôturée
  • Liste, détail, modification et suppression des interventions
  • Changement de mot de passe et authentification sécurisée

Technologies utilisées

PHP natif (sans framework), MySQL/MariaDB, Bootstrap pour l'interface. Développement avec Laragon, HeidiSQL et VS Code. Déploiement sur une VM accessible depuis le réseau local.

Difficultés & solutions

Sécuriser l'authentification des utilisateurs : mots de passe hashés en bcrypt. Faire fonctionner l'application une fois déployée sur le réseau local (et non plus sur mon poste) : configuration d'une constante d'URL adaptée. Déploiement sur la VM via clé USB, avec une documentation Word pour expliquer l'installation.

Compétences développées

  • Authentification sécurisée (bcrypt)
  • Conception de BDD (5 tables)
  • Déploiement sur un réseau local
  • Rédaction de documentation technique
03

GestMateriel

Application de gestion du parc informatique et des attributions

  • TypeApplication web interne
  • ContexteStage 1re année
  • Base de données3 tables
  • Données193 matériels, 133 attributions

Contexte & objectifs

Le parc matériel de la mairie était suivi dans un fichier Excel. L'objectif était de créer un outil web pour consulter et gérer l'inventaire et les attributions de matériel.

Fonctionnalités principales

  • Tableau de bord avec l'état du parc : en service, en stock, en panne, réformés
  • Liste des matériels (nom, marque, type, état, date d'ajout)
  • Suivi des attributions à la mairie et aux organismes externes
  • Ajout de nouveau matériel

Technologies utilisées

PHP natif, MySQL/MariaDB pour une base à 3 tables. Un script Python avec la librairie openpyxl a été écrit pour importer les données existantes depuis le fichier Excel.

Difficultés & solutions

Reprendre proprement des données réelles déjà existantes (environ 193 matériels et 133 attributions) sans erreur ni doublon lors de l'import. Un script Python dédié lit le fichier Excel et insère les données dans la base MySQL. L'application est documentée avec un fichier Word, comme GestInter.

Compétences développées

  • Scripting Python (openpyxl)
  • Import / migration de données réelles
  • Conception de BDD (3 tables)
