Veille technologique

Mon sujet de veille

J'ai choisi de suivre l'actualité de l'IA générative dans le développement logiciel : les nouveaux outils d'assistance au code, leur impact sur les pratiques de développement, et les évolutions rapides de ce secteur.

Mes outils de veille

Pour suivre ce sujet, j'ai mis en place deux outils : Feedly et Google Alerts.

Feedly

Feedly rassemble les nouveaux articles de plusieurs sites au même endroit : pas besoin d'aller sur chaque site un par un, les infos arrivent toutes seules. J'ai créé un dossier « Veille IA Dev » où j'ai ajouté des sources officielles et fiables, notamment le changelog de GitHub - le journal de bord officiel de la plateforme, où sont publiées quotidiennement les nouveautés, corrections de bugs et mises à jour déployées sur le site et sur leurs outils comme GitHub Copilot - ainsi que le site d'Anthropic, connu pour son produit phare, la famille de modèles d'IA Claude.

Google Alerts

Le deuxième outil, c'est Google Alerts, où j'ai créé une alerte sur le mot-clé « GitHub Copilot » : dès qu'un nouvel article sort sur le sujet, je le reçois. Ça permet de compléter Feedly, parce qu'on y trouve aussi des articles de presse et de sites spécialisés, en plus des sources officielles.

Octobre 2026

De l'autocomplétion à l'agent autonome : le tournant de GitHub Copilot

Ce qui m'a le plus marqué dans ma veille, c'est la bascule de GitHub Copilot : un outil qui ne faisait au départ que compléter une ligne de code propose désormais un « Agent Mode » capable de lire tout un projet, modifier plusieurs fichiers à la fois, exécuter des commandes dans le terminal, lancer les tests et corriger ses propres erreurs, un peu comme le ferait un collègue à qui on confierait une tâche. Cette évolution s'est faite en plusieurs étapes au cours de 2026, avec l'ajout progressif du support du protocole MCP (Model Context Protocol), qui permet de connecter l'agent à des outils externes (GitHub, bases de données, etc.).

Ce que je retiens pour mon propre usage : ces outils sont utiles pour gagner du temps sur des tâches répétitives, mais ils demandent toujours de comprendre le code produit avant de le valider, surtout sur un projet professionnel comme ceux que j'ai réalisés en stage.

Veille continue

Un secteur qui évolue très vite

Un des enseignements de cette veille, c'est la rapidité des changements : les fonctionnalités, les tarifs et les modèles disponibles évoluent presque chaque mois. D'où l'intérêt de garder une veille active via Feedly et Google Alerts plutôt que de se fier à une connaissance figée, pour rester à jour sur les outils que je pourrais utiliser en entreprise.
