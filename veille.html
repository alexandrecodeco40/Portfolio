Mon sujet de veille

J'ai choisi de suivre l'actualité de l'IA générative dans le développement logiciel : les nouveaux outils d'assistance au code, leur impact sur les pratiques de développement, et les évolutions rapides de ce secteur.

Mes outils de veille

Feedly

Un dossier dédié « Veille IA Dev » regroupe mes flux RSS, notamment le changelog de GitHub et le blog d'Anthropic, pour suivre les nouveautés au fil de l'eau.

Google Alerts

Une alerte sur le mot-clé « GitHub Copilot » me notifie des nouveaux articles publiés sur le sujet, en complément de Feedly.

Synthèses
